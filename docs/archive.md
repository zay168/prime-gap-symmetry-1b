# Cleanup archive

This repository previously contained many numbered exploratory files whose names overstated the level of proof, originality, or mathematical certainty.

They were removed from the main presentation because they mixed real experiments with speculative narration and made the project look less credible than the underlying idea.

Removed categories:

- proof-attempt scripts that mostly printed explanatory text;
- speculative Hardy-Littlewood or Riemann-zero narratives;
- old notes duplicated by the current concise research note;
- generated cache files;
- an incomplete Lean scaffold with placeholders.

The cleaned version keeps only the parts that are easy to explain, run, and defend.
